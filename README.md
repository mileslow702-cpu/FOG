# LOW VISIBILITY

A Miles Low first-person shooter — Do Better Network.

Static site, no build step: `index.html` plus three model files
(`soldier.model.js`, `michelle.model.js`, `world.model.js` — 3D models packed for the browser).
Cars, houses, props, the Haze Machine and the North Star rifle were generated with Higgsfield.

Street names and soundtrack live in the `CONFIG` block at the top of the script in `index.html`
(add songs as `{ title, src }` and drop the MP3s in a `music/` folder).
